# Garments ERP

React + Vite + Tailwind CSS v4 admin panel.

## Run
```
npm install
npm run dev
```
Open http://localhost:5173

Demo login: admin@garments.com / admin123

Modules: Dashboard, Buyers, Orders, Styles, Production, Inventory, Accounts, Reports, Settings.
Data is stored in browser localStorage (Settings > Reset Demo Data to restore).
