# React Property Management System

A React + TypeScript + Vite property management dashboard.

## Modules

Dashboard, Properties, Units, Owners, Tenants, Leases, Payments, Maintenance and Reports.

## Run

```bash
npm install
npm run dev
```

## Backend-ready

The frontend structure is prepared for a PHP + MySQL/MariaDB REST API. Suggested API modules:

- /api/properties
- /api/units
- /api/owners
- /api/tenants
- /api/leases
- /api/payments
- /api/maintenance
- /api/reports

The current pages use sample UI data so the dashboard can be built and tested before API integration.
